# Exp - 2 LIBRARY MANAGEMENT SYSTEM

# AIM:
To develop a Library Management System to manage books, student details, book issuing, book returning, and maintaining library records efficiently.

# SRS (Procedure):
Procedure:

Start the program.

Display the Library Management System menu.

Display the available operations:
    Add Book
    View Books
    Search Book
    Issue Book
    Return Book
    Exit

Allow the user to select an operation.
Enter the required book details such as book ID, title, and author name.

Store and manage the book records.

Perform book issuing and returning operations.

Update the book availability status after each transaction.

Display the updated book details.

Stop the program when the user selects Exit.
